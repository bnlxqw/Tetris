Klassikaline arkaadmäng, kus mängija juhib 10x20 suurusel väljal langevaid kujundeid (tetraminosid). Mängu eesmärk on moodustada horisontaalseid ridasid, mis täitumisel kaovad ja annavad punkte. Skoori kasvades mängukiirus suureneb.

Põhifunktsionaalsus:

Mänguloogika: Juhuslike kujundite genereerimine, pööramismehaanika, kokkupõrgete (põrkumiste) kontroll ja täis saanud ridade kustutamine.

Juhtimine: Kujundite liigutamine ja pööramine klaviatuuri abil reaalajas.

Kasutajaliides: Mänguvälja, skoori ja järgmise kujundi akna (Next Piece) visuaalne kuvamine.
